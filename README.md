I'm Ahan Sardar, a student engineer and full stack developer in Kolkata. I build across AI, web, Android and robotics.

- **CookAlong:** recipe search, step-by-step instructions and timers. Next.js, TypeScript and Supabase.
- **BharatScan:** on-device document segmentation, OCR and PDF annotation. Kotlin, Jetpack Compose, CameraX and ML Kit.
- **SPARKY:** voice, wake words and desktop automation. Python and Ollama. Vision is still under development.

**Toolkit:** Python, PyTorch, OpenCV, Ollama, scikit-learn; TypeScript, JavaScript, Next.js, React, Django, Flask; Kotlin, Android, Java, C++, Arduino, ROS; PostgreSQL, Supabase, Linux, Git, GitHub Actions.

**Process:** sketch the system; build the smallest useful version; break it and find what went wrong; make it clearer, faster and easier; ship, learn and make it a little better.

I'm interested in practical AI, thoughtful interfaces and systems that hold up beyond the demo.
